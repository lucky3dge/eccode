# ECCode Code Studio

Responsive ECCode lookup using the supplied 1,159-record workbook dataset.

## Run locally

```bash
python3 run_app.py
```

The launcher prints and opens the local URL. Keep the terminal open while using the app.

## Search, character, pinyin, and sound

- Search matches ECCode values and code components as you type.
- Each matching record displays its character from the record's Unicode field, its Pinyin (using the pinyin-pro browser library), and ECCode components.
- Press the speaker button beside a result or **Play pronunciation** in the detail panel to speak the character using the browser's Chinese speech voice, when available.
- Pinyin conversion uses a CDN script, so an internet connection is required for Pinyin labels. Character display and code search work without it; audio depends on browser speech synthesis and installed voices.
- All 1,159 source records and alternate code entries are retained. The workbook itself does not contain Pinyin; Pinyin is generated by the browser library.
